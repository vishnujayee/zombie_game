# WARD 13 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build one complete, finishable level of an original first-person retro horror zombie shooter ("WARD 13") that runs by double-clicking `index.html`.

**Architecture:** Software raycaster rendering into a 320×200 `ImageData` buffer. 15 classic-script modules attached to `window.W13`, wired by a tiny event bus, driven by one `requestAnimationFrame` loop with a state machine. Procedural pixel art; CC0 sound files with a procedural Web Audio fallback for every sound.

**Tech Stack:** HTML5 Canvas 2D, plain JavaScript (ES2020, no modules), Web Audio API + `HTMLAudioElement`. Dev only: Node 22 (`node:vm`, `node:assert`) and the preinstalled Playwright/Chromium.

**Spec:** `docs/superpowers/specs/2026-11-12-ward13-design.md` (what). `docs/ARCHITECTURE.md` (module contracts, events, pipeline). Executors read both, plus `CLAUDE.md`.

## Global Constraints

- Runs from `file://`: classic `<script>` tags only, **no ES modules, no `fetch`/XHR, no runtime dependencies, no build step**.
- Namespace: every module is `window.W13.<Name>`; load order is exactly as in ARCHITECTURE §3.
- Internal resolution **320×200**, CSS `image-rendering: pixelated`, letterboxed.
- All tuning numbers live in `js/config.js` with the spec's exact values (spec §4–§6).
- Every module exposes `reset()`; event listeners are registered once at boot (`init()`), never in `reset()`.
- Assets: CC0 or self-generated only, listed in `assets/sfx/CREDITS.md`. Every sound ID (spec §8) has a procedural fallback.
- Zero console errors; asset fallbacks log `console.warn` only.
- Original content only: no names, maps, sprites or music from existing games.
- Files stay under ~400 lines; split if larger.
- Do not run `playwright install`. Screenshots for self-checks use `deviceScaleFactor: 1`.
- **Git:** commit only if the user has allowed it in the current session (they asked for no commits on 2026-11-12, then approved one commit). Each task's "Checkpoint" step updates `CLAUDE.md` tags; the commit is part of that step only when allowed.

## Review Focus

1. **Shooting around corners:** an enemy whose centre is behind a wall edge must not take damage, even if part of its sprite shows. Expected: a hit needs the enemy closer than the wall along the shot ray. *Test → Task 6 `hitscan blocked by wall`.*
2. **Theatre door locking while the player stands in the doorway:** the player must never end up inside a solid tile. Expected: the theatre locks only once the player is fully inside the theatre zone, ≥0.6 tiles from the door. *Test → Task 9 `theatre locks only when player clear of door`.*
3. **Restart after death or mid-boss:** health, ammo, doors, enemies, wave index and stats all reset, and a shot plays its sound exactly once (no duplicate listeners). *Test → Task 9 `restart resets all state and listeners`.*
4. **Out of ammo with enemies alive:** there's no melee, so this would soft-lock the game. Expected: when total ammo is 0 and wave enemies are alive, a 12-round pistol ammo pickup appears near the player after 5 s. *Test → Task 9 `ammo mercy drop`. Add `Config.mercyAmmo = {delay:5, amount:12}`.*
5. **Pointer lock refused, Esc, tab hidden:** expected the game goes to PAUSED, there's no huge time jump on resume, and a click resumes. *Test → Task 4 `visibility hidden pauses` and `dt clamped to 0.05`.*

**Test conventions (used by all tasks):**
- `tests/harness.js` exports `load(files: string[]) -> W13` (evaluates `js/<file>` in one `vm` context with stubs: `window`, `document.createElement('canvas')` returning a fake 2D context with `createImageData/getImageData/putImageData/fillRect/drawImage`, `performance.now`, `Audio` stub, `AudioContext` stub, `addEventListener` no-op).
- `tests/run.js` provides global `test(name, fn)` and runs every `tests/*.test.js`, printing `PASS/FAIL name` and exiting 1 on any failure. Run all: `node tests/run.js`. Run one file: `node tests/run.js map`.
