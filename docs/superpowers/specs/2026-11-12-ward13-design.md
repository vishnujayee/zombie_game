# WARD 13 — Design Spec

**Status:** Design approved by user (2026-11-12). Awaiting spec review → implementation plan.
**Type:** New project, single playable level, first-person retro horror zombie shooter.

---

## 1. Goal & success criteria

Build one complete, polished, *finishable* level of an original first-person retro horror shooter that runs in a desktop browser by double-clicking `index.html`.

The game is "done" when **all** of these are true:

1. Opening `index.html` directly from disk (`file://`) shows the title screen with **zero console errors**.
2. The player can play from start → 3 waves → boss → exit gate → victory screen without soft-locks.
3. Death shows a "YOU DIED" screen; restart fully resets the level.
4. Every sound plays either from a CC0 file or from its procedural fallback — no silent failures, no crashes if a file is missing.
5. Visual style is consistently retro horror: 320×200 internal resolution, distance darkness, CRT/grain/vignette overlay.
6. Automated Playwright verification passes (see §10).

### Constraints (from user)
- First-person retro (raycaster) — chosen over top-down.
- Must actually work and be finished; one level only.
- Assets: open-source (CC0) or self-made; must be bundled and working.
- Weapons: pistol + shotgun. Length: 5–8 min, medium difficulty.

### Non-goals (YAGNI)
Multiple levels, save system, mobile/touch, gamepad, multiplayer, settings menu (beyond mute/sensitivity keys), level editor, true 3D/height variation, jumping, building/bundling tools.

## 2. Setting & narrative

**WARD 13** — an abandoned asylum at night. Power flickers; the patients have turned. The player wakes in reception and must reach the exit gate behind the operating theatre. Original IP; no names, art, maps or music copied from existing games.

Palette: near-black, sickly green, jaundiced yellow, rust, blood red.

---

## 3. Level flow

| # | Zone | Trigger to start | Content | Ends when |
|---|------|------------------|---------|-----------|
| 0 | Reception | Game start | Title card fades. Pistol (12 in mag + 24 reserve). One scripted zombie silhouette crosses the far corridor and vanishes (scare, not a spawn). | Player steps into lobby trigger |
| 1 | Lobby + west corridors | Lobby trigger | **Wave 1:** 8 Shamblers from 4 spawn points, staggered | All wave-1 enemies dead → supply-room door opens |
| — | Supply room | Wave 1 cleared | **Shotgun** pickup on gurney + ammo | Shotgun picked up |
| 2 | East wing / patient rooms | Shotgun pickup | **Wave 2:** 6 Shamblers + 3 Runners | All dead → stairwell door to morgue opens |
| 3 | Morgue (basement) | Enter morgue trigger | **Wave 3:** 4 Shamblers + 2 Runners + 2 Bloaters | All dead → operating-theatre door opens |
| 4 | Operating theatre | Enter theatre trigger (door locks behind) | **Boss: The Stitched** | Boss dead → exit gate unlocks, door behind reopens |
| 5 | Exit gate | Touch gate | — | Victory screen |

Total regular zombies: 25. Health/ammo pickups placed between zones (≈ 6 health, 8 ammo).

## 4. Player

| Property | Value |
|---|---|
| Health | 100 (max 100) |
| Walk / run speed | 2.6 / 4.2 tiles·s⁻¹ |
| Turn | Mouse (pointer lock), default sensitivity 0.0025 rad/px; arrow keys turn at 2.5 rad·s⁻¹ |
| Collision radius | 0.25 tiles |
| View | FOV 66°, fog/darkness from 2.5 tiles to black at 9 tiles |

Controls: **WASD** move, **mouse** look, **LMB** fire, **R** reload, **1/2** weapon, **Shift** run, **E** use (doors/gate — doors also open on walk-in), **Esc** pause, **M** mute.

## 5. Weapons (hitscan)

| | Pistol | Shotgun |
|---|---|---|
| Damage | 34 per shot | 18 per pellet × 7 |
| Spread | ±0.5° | ±6° |
| Fire interval | 0.28 s | 0.9 s (incl. pump) |
| Magazine / reserve start | 12 / 24 | 6 / 12 (on pickup) |
| Reload | 1.1 s | 0.45 s per shell (interruptible by firing) |
| Range | 20 tiles | 10 tiles (damage falloff after 4) |

Hit resolution: ray cast against wall DDA distance; nearest enemy whose angular half-width contains the ray and is closer than the wall is hit. Muzzle flash raises light level for 80 ms. Shots emit a "noise" event (radius 10 tiles) that alerts enemies.

## 6. Enemies

| Type | HP | Speed (tiles/s) | Attack | Notes |
|---|---|---|---|---|
| Shambler | 100 | 0.9 | Melee 10 dmg, 1.0 s cooldown, range 0.8 | Idle sway; groans periodically |
| Runner | 60 | 3.0 | Melee 7 dmg, 0.6 s cooldown | Screech on alert; 0.5 s windup before sprint |
| Bloater | 200 | 0.6 | Melee 15 dmg | On death bursts: 30 dmg within 1.5 tiles (hurts player & enemies), green splat |
| **The Stitched** (boss) | 1400 | 1.4 | Swipe 20 dmg (range 1.2) | **Phase 2 (<50% HP):** charge (5 tiles/s, 25 dmg, 3 s cooldown, telegraphed by roar + 0.7 s stop) and bile projectile (12 dmg, speed 5, every 2.5 s). Arena lights flicker red. |

AI state machine per enemy: `IDLE → ALERT → CHASE → ATTACK → (HURT) → DEAD`. Alert when the player is in line-of-sight within 8 tiles (LOS via grid ray) or a noise event reaches it. Chase uses direct steering with wall-slide + simple "unstick" (try ±45° when blocked); wave enemies spawn already alerted toward the player so nobody gets stuck idle. Enemies separate from each other (soft push) so they don't stack into one sprite.

Animation frames (procedural sprites, 64×64): walk ×4, attack ×2, hurt ×1, death ×4 (corpse stays as last frame).

## 7. Visuals

- Internal canvas 320×200, CSS-scaled with `image-rendering: pixelated`, integer scale where possible, letterboxed.
- Textured walls (64×64), flat-shaded floor/ceiling with distance gradient (no floor casting — perf/scope).
- Light model: `brightness = clamp(ambient + muzzleFlash + tileLight − distance·falloff)`. Some tiles flicker (random dropout). Boss arena flickers red in phase 2.
- Sprites billboarded with per-column depth test against wall z-buffer; sorted far→near.
- Weapon view-model at bottom: bob while walking, recoil kick, muzzle flash frame.
- Post FX: scanlines, animated grain, vignette, red damage flash, screen shake, low-health (<30) desaturation pulse synced to heartbeat.

Textures (procedural, deterministic seed): `TILE` (dirty white tiles), `TILE_BLOOD`, `CONCRETE`, `METAL_DOOR`, `MORGUE_DRAWERS`, `THEATRE_DOOR` (locked, red light), `EXIT_GATE` (bars, green exit sign when unlocked), `PADDED_CELL`.

## 8. Audio

- CC0 files in `assets/sfx/` (OGG primary). Sources: CC0-licensed packs (e.g. Kenney, OpenGameArt CC0). Every file listed in `assets/sfx/CREDITS.md` with source URL + license.
- Sound IDs: `pistol`, `shotgun`, `pump`, `reload`, `empty`, `zombie_groan_1..3`, `runner_screech`, `bloater_burst`, `boss_roar`, `boss_hit`, `player_hurt`, `player_death`, `footstep`, `pickup`, `door`, `ambience`, `heartbeat`.
- Each ID also has a WebAudio procedural fallback (noise bursts, filtered oscillators). If a file fails to load or is absent → fallback is used silently, one console `warn` (not error).
- If network downloads are impossible during build, ship procedural-only and say so.
- Positional: gain by distance, stereo pan by relative angle (StereoPannerNode).
- Audio context starts on the title-screen click (browser autoplay policy).

## 9. Screens / states

`TITLE → PLAYING ⇄ PAUSED → DEAD | VICTORY → (restart) PLAYING`.
- Title: flickering "WARD 13" logo, "CLICK TO ENTER", controls list.
- Dead: blood-red fade, "YOU DIED", click to restart.
- Victory: "YOU ESCAPED", time, kills, accuracy, click to play again.
- Losing pointer lock during play → PAUSED.
- HUD: bottom bar — health (number + bar), weapon icon, ammo `mag / reserve`, wave indicator `WAVE 2 — 5 LEFT`, centered crosshair, transient message line ("The supply room is open").

## 10. Robustness & verification

- Fixed max delta (`dt ≤ 0.05 s`); pause on `visibilitychange`.
- All runtime errors in the loop caught once, logged, and game paused with on-screen message instead of a frozen frame.
- No `fetch`/XHR at runtime (breaks on `file://`); audio via `HTMLAudioElement`.
- Debug mode `?debug=1`: god mode (G), skip wave (N), noclip (C), FPS counter.
- **Verification (Playwright, headless Chromium):**
  1. Load `file://…/index.html` → no console errors/pageerrors.
  2. Start game → screenshot each zone.
  3. Debug-skip through waves 1–3 and boss → assert state reaches `VICTORY`.
  4. Force player death → assert `DEAD` → restart → assert reset (health 100, wave 0).
  5. Map validation script: closed border, all spawns/pickups on floor tiles, every zone reachable from start (BFS treating openable doors as passable).
- Target ≥ 50 FPS at 320×200 on a mid laptop.
